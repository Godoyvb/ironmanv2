Introdução:
Este jogo é uma versão personalizada do projeto Iron Man desenvolvida em Python com Pygame. O jogador controla um zagueiro que deve desviar de um atacante enquanto um juiz decorativo se movimenta pela tela. A proposta é oferecer uma experiência simples e divertida, com pausa por tecla, registro de pontuação e telas de início e fim de jogo.

Tecnologias utilizadas:
- Python 3
- Pygame
- JSON para armazenamento de pontuações
- pyttsx3 (ainda não implementado, previsto como requisito)

Bibliotecas:
- pygame
- json (biblioteca padrão)
- datetime (biblioteca padrão)

Funções principais implementadas:
- `limpar_tela()`
- `inicializarBancoDeDados()`
- `escreverDados(nome, pontos)`
- `maior_pontuador()`
- `pausar_jogo(tela, fonte, branco, preto, relogio)`
- `name_entry()`
- `welcome_screen(nome)`
- `jogar(nome)`
- `dead(nome, pontos)`
